# RevitilianosVIP

Instaladores e arquivos de atualizacao dos apps VIP do **Revitilianos**:

- Tour Revitiliano 360
- IFC Ready
- AlanPoint
- Conversor Universal

Cada app tem seus releases com a tag `<app>-v<versao>`. O `manifest.json` guarda a versao
mais nova de cada um: o Revitilianos (bandeja do Windows) le esse arquivo para instalar e avisar
de atualizacoes. Nao edite o manifesto a mao - ele e gerado pelo script de publicacao.
